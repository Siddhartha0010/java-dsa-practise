HashSet is a collection that stores UNIQUE values only. Used to check whether an element is present or not.
Uses: Fast search,no duplicates
Creation of HashSet: HashSet<Integer> set = new HashSet<>();
OPERATIONS:
1)add:   set.add(5)    set.add(10);    o/p: [5,10]
2)contains:   set.contains(10);        o/p: true
3)remove:    set.remove(10);           o/p: [5]
4)size:      set.size();               o/p: 1
5)isEmpty:   set.isEmpty();            o/p: false
6)clear:     set.clear()               o/p:[]

Iteration:    for(int x:set){ SOP(x);}               //order is random while printing
